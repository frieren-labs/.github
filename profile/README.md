# frieren-labs

Organization for the [Frieren Desk](https://github.com/frieren-labs/frieren-desk) desktop pet.

A chibi Frieren that lives on your Hyprland desktop. Click her to chat with [opencode](https://opencode.ai), and ask her to read, edit or run things on the system.
